# 滩摊 · 管理端

**简体中文** | [English](README.en.md)

React + TypeScript + Vite 应用。请先按照[根目录快速启动](../README.md#快速启动)准备 MySQL 和 API。

在仓库根目录运行：

```bash
npm run dev -w admin-app
npm run build -w admin-app
npm run typecheck -w admin-app
```

访问 `http://localhost:3002`。开发模式下 `/api` 代理至 `http://localhost:8787`。

演示账号、功能边界与三端完整流程见[项目介绍](../README.md)和[演示说明](../docs/demo.md)。

# 第三方素材与外部服务

仓库保留了原项目使用的远程示例素材和第三方依赖。以下清单用于说明来源与运行依赖，不代表所有素材拥有同一种授权，也不代表项目作者拥有这些素材的著作权。

| 类型 | 代码中的来源 | 用途与说明 |
| --- | --- | --- |
| 示例照片 | `images.unsplash.com` | 商户、菜品、头像及展示图片；主要见各端 `data.ts` 和部分组件。图片不代表真实商户、菜品或经营资质 |
| 字体 | `fonts.googleapis.com` | Noto Sans SC、Fredoka、Outfit、Inter 等；由各端 HTML 引用，字体可能因网络不可用而回退 |
| Tailwind 样式运行时 | 各前端 `public/tailwind.js` | 三端包含本地脚本，避免样式依赖 CDN 可用性；应按原依赖许可使用，后续可迁移到构建时样式 |
| 图标 | npm 包 `lucide-react` | 通用界面图标；各端还包含项目内 SVG 装饰组件 |
| 地理位置描述 | `geocode.maps.co` | 顾客端在浏览器定位后请求地点描述；依赖定位授权、网络及服务可用性 |
| AI | `@google/genai` | 可选的推荐和海岛提示；需自行配置密钥 |
| 图片存储 | S3 兼容服务 | 可选的商户图片和付款凭证上传；需自行配置服务、凭据及访问规则 |

公开展示时，应将内置店铺与评论视为演示数据。示例图片尤其不能作为实际经营许可证或真实用户评价的证明。

本次整理未为整个项目添加统一开源许可证。各 npm 依赖、字体和图片遵循各自适用的许可或条款；若进一步商业使用或重新分发素材，应核对具体来源和授权范围，并保留必要声明。

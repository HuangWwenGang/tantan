# TanTan · Customer App

[简体中文](README.md) | **English**

A React + TypeScript + Vite application. First, set up MySQL and the API using the [root quick-start guide](../README.en.md#quick-start).

Run these commands from the repository root:

```bash
npm run dev -w c-app
npm run build -w c-app
npm run typecheck -w c-app
```

Open `http://localhost:3000`. In development, `/api` requests are proxied to `http://localhost:8787`.

See the [project overview](../README.en.md) and [demo walkthrough](../docs/demo.en.md) for demo accounts, feature boundaries, and the complete workflow across all three applications.
